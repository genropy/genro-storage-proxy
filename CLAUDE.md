### Project Purpose
HTTP microservice that exposes genro-storage capabilities via REST API. Acts as a storage aggregator for microservice architectures, enabling polyglot services to use storage via HTTP.

### Project-Specific Guidelines

**Key Features (Planned):**
- Polyglot architecture support
- Centralized storage configuration
- Backend transparency
